OCR 项目环境配置与运行指南

适用目录：C:\Users\lenovo\Desktop\OCR total　｜　Windows 11

1. 项目结构与端口

组件目录技术与版本端口
Python OCR 服务ocr-python-servicePython 3.10/3.11、Flask、PaddleOCR5001
Java 业务后端ocr-business-serverJDK 17、Maven 3.9+、Spring Boot8080
Web 前端ocr-webNode.js LTS、npm、Vue 3、Vite5173
正确启动顺序：Python OCR 服务 → Java 后端 → Vue 前端。三个服务分别占用一个终端窗口，运行期间不要关闭。

2. Java 17 配置

已安装的 JDK 路径：

C:\Users\lenovo\AppData\Local\Programs\Eclipse Adoptium\jdk-17.0.20.8-hotspot

用户环境变量：

JAVA_HOME=C:\Users\lenovo\AppData\Local\Programs\Eclipse Adoptium\jdk-17.0.20.8-hotspot
Path 新增：%JAVA_HOME%\bin

检查命令：

where java
java -version

应优先找到 Adoptium 路径，并显示 Java 17。若仍找到 Java 8，检查系统变量 Path 中是否残留 Oracle 的 java8path 或 javapath。

3. Maven 配置

已使用 Maven 3.9.16，目录：

C:\Users\lenovo\Desktop\apache-maven-3.9.16

用户环境变量：

MAVEN_HOME=C:\Users\lenovo\Desktop\apache-maven-3.9.16
Path 新增：C:\Users\lenovo\Desktop\apache-maven-3.9.16\bin

检查命令：

echo %MAVEN_HOME%
where mvn
mvn -version

输出应包含 Maven 3.9.16 和 Java 17。如果在 VS Code 内修改环境变量，需要彻底关闭所有 VS Code 窗口并重新打开；只新建终端标签页不会刷新环境。

4. Python OCR 环境

推荐使用 Python 3.10 或 3.11（64 位），不要用 Python 3.13。当前使用 Conda 虚拟环境 jrrg。

激活环境并安装依赖

conda activate jrrg
python --version
cd /d "C:\Users\lenovo\Desktop\OCR total\ocr-python-service"
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

如果当前不在 Python 服务目录，也可直接使用完整路径：

python -m pip install -r "C:\Users\lenovo\Desktop\OCR total\ocr-python-service\requirements.txt"

创建配置文件

cd /d "C:\Users\lenovo\Desktop\OCR total\ocr-python-service"
copy .env.example .env

没有安装 Tesseract 时，将 .env 设置为：

TESSERACT_CMD=
VERIFY_WITH_TESSERACT=false

若安装了 Tesseract，并带有中文和英文语言包：

TESSERACT_CMD=C:\Program Files\Tesseract-OCR\tesseract.exe
TESSERACT_LANG=chi_sim+eng
VERIFY_WITH_TESSERACT=true

Windows CPU 的 oneDNN 兼容处理

若出现 ConvertPirAttribute2RuntimeAttribute not support，先在 .env 末尾增加：

FLAGS_use_mkldnn=0

如仍报同样错误，在 ocr_service\ocr_engine.py 创建 PaddleOCR 的参数中加入：

enable_mkldnn=False,

RequestsDependencyWarning、没有 ccache、模型已缓存等提示通常不是导致任务失败的致命错误。

启动与检查

cd /d "C:\Users\lenovo\Desktop\OCR total\ocr-python-service"
conda activate jrrg
python app.py

另开终端检查：

curl http://127.0.0.1:5001/health

返回内容中的 ready 应为 true。

5. 启动 Java 后端

cd /d "C:\Users\lenovo\Desktop\OCR total\ocr-business-server"
mvn spring-boot:run

首次运行会联网下载 Maven 依赖。出现以下日志即表示成功：

Tomcat started on port 8080
Started OcrBusinessApplication

终端不返回提示符是正常的，因为服务正在监听端口。按 Ctrl+C 才会停止。

6. Node.js 与前端

安装 Node.js LTS（推荐 Node.js 22 或更新的兼容 LTS），npm 会随 Node.js 一起安装。winget 命令：

winget install --id OpenJS.NodeJS.LTS -e --source winget

安装后彻底重启 VS Code/终端，再检查：

node --version
npm --version

安装前端依赖并启动：

cd /d "C:\Users\lenovo\Desktop\OCR total\ocr-web"
npm ci
npm run dev

浏览器访问：

http://localhost:5173

8. 常见故障检查

现象处理方法
mvn 不是内部或外部命令检查 MAVEN_HOME 和用户 Path；彻底重启 VS Code。
npm 不是内部或外部命令安装 Node.js LTS，重启终端后检查 node --version。
找不到 requirements.txt进入 ocr-python-service，或对依赖文件使用完整路径。
前端返回 HTTP 500查看 Python 服务窗口最后一段完整 Traceback；Java 通常只是转发了 Python 错误。
端口被占用检查 5001、8080、5173 是否已有旧服务运行，先用 Ctrl+C 停止旧进程。
旧版 .doc 无法解析安装 LibreOffice 并加入 Path；.docx 不需要。
提示：默认数据库是本地 H2，无需安装 MySQL；上传文件默认限制为 50 MB。首次 OCR 可能下载模型，因此耗时较长并需要联网。
